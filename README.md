# Resume Builder Web App 💼

A simple, interactive, browser-based resume builder that allows users to create a formatted resume by entering their details into a form. It runs directly in the browser without requiring a backend or installation.

## ✨ Features

- **Simple User Interface:** Enter resume information through an HTML form.
- **Live Resume Generation:** Display a formatted resume using the information provided.
- **Client-Side Application:** Runs directly in the browser.
- **Responsive Styling:** Clean layout styled with CSS.
- **LinkedIn Integration:** Display a clickable LinkedIn profile link.
- **Resume Sections:**
  - Personal Information
  - Professional Summary
  - Skills
  - Work Experience
  - Education

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or backend are required.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/sathvikachidhirala/resume-builder-html.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your web browser.
4. Fill in the form to generate your resume.

## 🎯 Project Objective

The objective of this project is to demonstrate how HTML, CSS, and JavaScript can be used to build an interactive web application that collects user input and displays a structured resume.
